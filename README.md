# 📌 Project Description

This project focuses on analyzing store sales data to identify sales trends, evaluate business performance, understand customer purchasing behavior, and generate actionable insights to support data-driven decision-making.

---

# 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Identify top-performing products and categories.
- Explore sales trends over time.
- Compare performance across regions and customer segments.
- Generate data-driven insights and recommendations.
