# 📌 Project Description

A team-based data analysis project focused on exploring Superstore sales data through an end-to-end analytical workflow.

The project follows multiple stages, starting with data cleaning and preparation in Microsoft Excel, followed by data storage and querying using SQL, exploratory data analysis (EDA) with Python, and finally, interactive dashboard development using Power BI.

The analysis aims to understand sales and profitability performance, identify top-performing products and categories, explore trends over time, and evaluate regional and customer segment performance to generate actionable business insights.

---

# 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Identify top-performing products and categories.
- Explore sales trends and patterns over time.
- Compare performance across regions and customer segments.
- Evaluate key business performance indicators (KPIs).
- Generate actionable, data-driven insights and recommendations.

## 📊 Key Performance Indicators (KPIs)

The project focuses on the following core business metrics:

| KPI | Definition |
|---|---|
| Total Sales | Total revenue generated from all orders |
| Total Profit | Total profit generated from sales |
| Profit Margin | Total Profit ÷ Total Sales × 100 |
| Average Order Value (AOV) | Total Sales ÷ Number of Orders |
| Order Count | Total number of orders |
| Total Quantity Sold | Total units sold across all orders |

These KPIs will be used to evaluate business performance and support comparisons across products, categories, regions, and customer segments.
